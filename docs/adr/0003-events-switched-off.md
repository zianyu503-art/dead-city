# 0003 活動用開關關閉，不刪程式碼

## 背景
國慶活動在 2026-10-15 結束。玩家要撤掉所有活動福利：國慶特別版、全場三折、國慶限定武器。已經買到的活動武器要能繼續用，競技場要保留國慶殭屍和武器。以後新年可能還要辦類似的活動，所以不要刪掉。

## 決定
- 加兩個開關：`EVENT_ON` 控制國慶特別版卡片和活動武器的購買與取得，`SALE_ON` 控制全場三折，兩個都設成 `false`。
- 活動武器用 `eventItem: true` 標記。活動關閉時商店只列出已經擁有的活動武器，買不到也拿不到。
- 國慶殭屍、國慶地圖、煙火秀、活動武器的程式和模型全部留著；競技場照樣能召喚國慶殭屍、選活動武器。
- 感染者圖鑑裡只在國慶特別版出現的殭屍，改成顯示「目前只在競技場出現」。

## 後果
- 重辦活動只要打開開關，再把文字（國慶、10/1–10/15）換成新的主題和日期。
- 已經擁有活動武器的玩家不受影響。
- 國慶期間的日期判斷（`eventDaysLeft`）還在，打開 `EVENT_ON` 後仍然只在 10/1–10/15 開放，要辦別的節日得一起改。
