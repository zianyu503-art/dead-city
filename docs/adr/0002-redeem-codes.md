# 0002 兌換碼只存雜湊，明碼不進 repo

## 背景
玩家要能在主選單輸入兌換碼領禮物，兌換碼藏在關卡的牆上，而且「不能讓別人猜得到」。遊戲是純前端（GitHub Pages 和 claude.ai artifact），沒有伺服器，而且 repo 是公開的，任何人都看得到 `index.html` 和 Blender 腳本。

## 決定
- 遊戲裡只存每組兌換碼加鹽（`deadcity:`）後的 SHA-256 雜湊，輸入時把字串轉大寫、去掉空白和破折號後比對。
- 明碼只放在 git 忽略的 `.secrets/redeem-codes.json`。`tools/blender/graffiti.py` 從那裡讀出兌換碼，轉成字形網格噴在牆上，所以它只以幾何形狀存在於 `assets/models/graffiti.glb`，不會以文字出現在任何檔案裡。
- 兌換碼用 31 個不易看錯的字元（沒有 0、O、1、I、L）隨機產生 10 碼，約 49 位元，猜不出來；連續輸錯 5 次鎖 60 秒，擋住亂試。
- 「只能用一次」以每台裝置為單位：已兌換的雜湊存在 localStorage。

## 後果
- 想拿到兌換碼就得進黃昏住宅區找到那面牆（或去翻模型的幾何），這正是設計要的玩法。
- 沒有伺服器，做不到「全世界只有第一個人能兌換」；要做就得另外架後端。
- 清掉瀏覽器資料就能再兌換一次，但金錢也存在同一處，會一起清掉。
- 換新的兌換碼：改 `.secrets/redeem-codes.json`，重跑 `graffiti.py`，再把 `sha256('deadcity:' + 去掉破折號的大寫兌換碼)` 填進 `index.html` 的 `REDEEM`。
